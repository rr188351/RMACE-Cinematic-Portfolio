Procedural Skill Tree Framework

Overview

A modular, cinematic skill tree framework built in Unreal Engine 5.6. Designed for RPGs and action games, this system supports procedural node generation, save/load persistence, and cinematic UI polish. The skill tree is data-driven and procedurally generated — no manual node placement required. Simply add entries in a DataTable and the system auto-creates nodes with connections, icons, and behaviors.

Core Features

  • Procedural Node Generation — nodes auto-spawn from DataTable entries (ID, Name, Icon, Prerequisites, Flags).
  • Save Game State — learned/unlearned nodes persist across sessions via a USaveGame subclass.
  • Learnable / Unlearnable Flags — dynamic conditions toggle skill availability.
  • Hover FX + Animations — glow, spin, circle-to-hex transform and sound cues.
  • Skill Unlock FX — Niagara particle bursts themed per skill.
  • Zoom / Pan Controls — smooth viewport navigation with auto-center (0.7s snap).
  • Single Component Control — all behaviors centralized in SkillTreeManager.
  • GAS Integration — designed to connect with gameplay abilities.
  • Performance Optimization — Soft References and asynchronous asset loading keep the UI responsive.

Architecture

SkillTreeManager (central component) ├── NodeWidget (UMG) ├── DataTable (FSkillData struct) ├── SaveSystem (USaveGame subclass) ├── FX (Niagara emitters, SoundCues) └── InputHandler (zoom, pan, auto-center)

Procedural Generation

Add a new skill in the DataTable → auto node spawn. Connections auto-map based on prerequisites, and the hexagonal layout ensures cinematic symmetry.

Save System

A USaveGame subclass stores unlocked node IDs. Auto-loads on game start and supports learn/unlearn toggles.

UI & FX

  • Hover: glow aura + spin animation + sound cue.
  • Select: impact sound + particle burst.
  • Unlock: themed FX — gold sparks, fire embers, ghostly mist.
  • Opening Animation: each skill has a unique intro FX.

Controls

Pan

Drag viewport

Zoom

Scroll in / out

Auto-Center

Smooth snap (0.7s) to clicked node

Easing

Curve assets used for animations

Performance

Soft References and asynchronous asset loading reduce initial load cost. Build size was reduced from 10.3 MiB → 4.5 MiB through optimized loading of skill icons and FX.

Customization & Future Plans

Add new skills via DataTable only; replace icons, sounds and FX per skill theme; adjust zoom/pan speed in SkillTreeManager. Future plans include plugin packaging for the Unreal Marketplace, expanded node types (passive / active / ultimate) and multiplayer sync for co-op RPGs.

RM_MenuUI Plugin

Overview

A reusable Unreal Engine plugin built on Common UI for scalable menu systems — drop it into any project's Plugins folder and enable it to get a complete, modular game menu framework.

Features

  • Menu System — modular, reusable menus powered by Common UI.
  • Graphics Settings — resolution, quality presets, and display options.
  • Audio Settings — volume sliders, mute toggles, and sound profiles.
  • Display Controls — fullscreen/windowed modes, brightness, and scaling.
  • Input Controls — Enhanced Input mapping with profiles for keyboard, controller, and touch.
  • Save / Load System — game settings persist across sessions.
  • Credits Screen — cinematic scrolling credits with audio integration.
  • Continue / Resume Flow — seamless game resume from the last save.
  • Asynchronous Operations — smooth UI updates without blocking gameplay.

Prerequisites

Enable Common UI in Project Settings, and enable Enhanced Input both as a plugin and in Project Settings. Note: localization works properly only in Standalone mode, not in PIE (Play In Editor).

Installation

Copy the RM_MenuUI folder into your project's Plugins/ directory, restart Unreal Engine, then enable the plugin via Edit → Plugins.

C++ FPS Shooting Game

Objective

Develop a First-Person Shooter (FPS) game in Unreal Engine using native C++ APIs only. The game dynamically spawns interactive boxes based on online JSON data; the player shoots and damages these boxes, earning points upon destruction.

Online JSON Data

Boxes are spawned from JSON hosted online at this data source. Each box entry includes:

  • Type — for future expansions.
  • Color — applied dynamically to the material.
  • Health — initial health value.
  • Score — points awarded upon destruction.

Error handling covers HTTP request failure, JSON parse errors, and invalid/missing fields.

Box Spawning

Boxes spawn via SpawnActor with collision handling. Attributes are applied using ApplyBoxStats() in C++. The spawner injects DestroySound and DestroyEffect centrally. A simple cube mesh is used (UE default).

Custom Material

A Material Instance Dynamic (MID) is created with a Base Color parameter. The color is parsed from JSON and applied in C++: DynMat->SetVectorParameterValue("Base Color", BoxColor)

Shooting Mechanics

Implemented using a line trace / projectile system. On hit, box health is reduced by 1; when health reaches 0 the box is destroyed with a sound and particle effect, and the score is incremented via ShooterGameMode.

Scoreboard UI

Built with UUserWidget (C++ base + UMG extension). Displays the player's current score and updates dynamically when a box is destroyed.

Project Structure

Source/ └── Practce/ ├── Public/ │ ├── MyClass.h // BoxActor class (health, score, color, effects) │ ├── BoxSpawner.h // Spawner class (JSON fetch + spawn logic) │ ├── ShooterGameMode.h // Game mode (score handling) │ └── ShooterHUD.h // UI base class │ ├── Private/ │ ├── MyClass.cpp // BoxActor implementation (damage, destroy, effects) │ ├── BoxSpawner.cpp // JSON parsing + spawn logic │ ├── ShooterGameMode.cpp// Score increment logic │ └── ShooterHUD.cpp // UI update logic │ └── Practce.Build.cs // Build configuration

Requirements & Conclusion

All gameplay logic was written in C++ only, with UMG used only for UI (C++ base class required), default UE assets and smooth performance. The project demonstrates data-driven gameplay using online JSON, C++ mastery in Unreal Engine, and cinematic polish with sound and particle effects.
