Skill Tree UMG

🎮 View Details 
🎮 Procedural Skill Tree System (Unreal Engine)
A modular, cinematic skill tree framework built in Unreal Engine 5.6.
Designed for RPGs and action games, this system supports procedural node generation, save/load persistence, and cinematic UI polish.

📝 Overview
This skill tree system is data‑driven and procedurally generated.
No manual node placement required — simply add entries in a DataTable, and the system auto‑creates nodes with connections, icons, and behaviors.

🚀 Core Features
Procedural Node Generation
Nodes auto‑spawn from DataTable entries (ID, Name, Icon, Prerequisites, Flags).
Save Game State
Learned/unlearned nodes persist across sessions.
Learnable/Unlearnable Flags
Dynamic conditions toggle skill availability.
Hover FX + Animations
Glow, spin, circle‑to‑hex transform, sound cues.
Skill Unlock FX
Niagara particle bursts themed per skill.
Zoom/Pan Controls
Smooth viewport navigation with auto‑center (0.7s snap).
Single Component Control
All behaviors centralized in SkillTreeManager.

🏗 Architecture
SkillTreeManager (central component)
 ├── NodeWidget (UMG)
 ├── DataTable (FSkillData struct)
 ├── SaveSystem (USaveGame subclass)
 ├── FX (Niagara emitters, SoundCues)
 └── InputHandler (zoom, pan, auto‑center)

🔄 Procedural Generation
Add new skill in DataTable → auto node spawn.
Connections auto‑map based on prerequisites.
Hexagonal layout ensures cinematic symmetry.

💾 Save System
USaveGame subclass stores unlocked node IDs.
Auto‑load on game start.
Supports learn/unlearn toggles.

🎨 UI & FX
Hover: Glow aura + spin animation + sound cue.
Select: Impact sound + particle burst.
Unlock: Themed FX (gold sparks, fire embers, ghostly mist).
Opening Animation: Each skill has unique intro FX.

🎮 Controls
Pan: Drag viewport.
Zoom: Scroll in/out.
Auto‑Center: Smooth snap (0.7s) to clicked node.
Curve Assets: Used for easing animations.

⚙️ Customization
Add new skills via DataTable only.
Replace icons, sounds, FX per skill theme.
Adjust zoom/pan speed in SkillTreeManager.

🔮 Future Plans
Plugin packaging for Unreal Marketplace.
Website showcase with demo GIFs.
Expanded node types (passive/active/ultimate).
Multiplayer sync for co‑op RPGs.
