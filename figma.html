Overview

FitPulse (Fitnplus) is a modern fitness and health tracking application — "Track. Improve. Achieve." It is designed to help users monitor their daily activity, workouts, health metrics, progress, and fitness goals through a clean and interactive interface. This is the actual coded application, built with React, Vite and Tailwind CSS.

Goals

  • Build a production-style React application.
  • Practice component-based architecture and create reusable UI components.
  • Implement responsive layouts across desktop, tablet and mobile.
  • Explore animation and interaction design.
  • Apply UX principles and connect UI design with the actual frontend implementation.

UI/UX Design

The interface focuses on simple navigation, personalized health insights, visual progress tracking, workout management, activity monitoring and community challenges — with smooth micro-interactions and light/dark theme support.

Screens / Views

Home

App entry with splash animation

Dashboard

Steps, heart rate, calories, hydration, sleep, stress, daily streak & AI insights

Workouts

Running · walking · cycling · strength · yoga · HIIT

Activity Log

Step history, heart rate, calories, sleep, stress, hydration

Community Challenges

Leaderboards · achievements · share progress

Progress Review

Profile · goals · device sync · settings · help

Design Approach

FitPulse was designed using a user-centered workflow — user persona, empathy map, information architecture, user flow, wireframes, visual design, prototype, then a React implementation.

Components & Interactions

  • Dashboard cards for steps, heart rate, calories, hydration, sleep, stress and daily streak.
  • SVG / Recharts data visualization with animated charts and progress rings.
  • Number count-up animations, logo reveal, screen transitions and staggered card entrances.
  • Light / dark theme with instant switching.

Prototype / Figma

The design source lives in the project's .figma/ folder inside the FitPulse repository.
